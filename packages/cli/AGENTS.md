# AGENTS.md

## Purpose

`@jarvis/cli` — CLI text chat client for the Jarvis AI assistant. Currently a template that prints "Hello World" on start; real chat functionality comes later.

## Stack

- TypeScript (strict, ES2020, CommonJS)
- Tests via Vitest

## Scripts

Run from `packages/cli`:

| Command         | Description                   |
| --------------- | ----------------------------- |
| `npm run build` | Compile TypeScript to `dist/` |
| `npm run dev`   | Run the CLI in dev mode       |
| `npm start`     | Run the compiled CLI          |
| `npm test`      | Run the test suite            |
